# Citing AI Provenance Spec

Tier-2 reference.
This file explains how AI Provenance Spec is licensed and how to cite
the v1 specification when you reference it elsewhere.

## Machine-readable citation

[`CITATION.cff`](../../CITATION.cff) at the repository root is the
machine-readable source of truth for citation metadata.
GitHub and Zenodo read
it to render a "Cite this repository" widget.
If the attribution below and
`CITATION.cff` ever disagree, `CITATION.cff` wins.

## Attribution

> AI Provenance Spec: Trusted Release Substrate for Portable Cognition Capsules
> (v1 specification). Jonathan A. Bowe, 2026. Apache-2.0.

When you cite a specific claim, point at the file and line — for example
`docs/governance/constitution.md:142`.

## Suggested citation slug

`Bowe 2026, AI Provenance Spec v1`

## BibTeX

```bibtex
@misc{bowe2026aegisdrop,
  author       = {Bowe, Jonathan A.},
  title        = {AI Provenance Spec: Trusted Release Substrate for Portable
                  Cognition Capsules},
  year         = {2026},
  note         = {v1 specification},
  howpublished = {\url{https://github.com/jonathan-kellerai/ai-provenance-spec}},
  license      = {Apache-2.0}
}
```

## Companion specification

Aegis Drop composes with its sister specification, Grounded RAG
([`github.com/jonathan-kellerai/grounded-rag-spec`](https://github.com/jonathan-kellerai/grounded-rag-spec)).
If your work cites the combined trust posture — trust the release (AI Provenance Spec)
and trust the capsule (Grounded RAG) — cite both specifications.
